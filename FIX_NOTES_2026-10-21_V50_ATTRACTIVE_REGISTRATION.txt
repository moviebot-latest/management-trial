V50 — Registration and Account Created Experience

1. Registration page
   - Keeps the existing Flask registration form and server-side validation.
   - Adds a Details / Verify / Complete progress indicator, clearer security note, and mobile single-column layout.
   - Adds browser autocomplete hints and a password complexity pattern matching validate_password().
   - Fixes the password strength bar off-by-one issue when every rule is met.
   - Updates mismatch feedback when either password field changes.

2. Email verification
   - OTP email template now uses a branded, responsive email layout with a clear code, expiry reminder, and safety note.
   - Resend countdown is based on last_sent_at from the database; the server remains authoritative.
   - Existing OTP expiry and attempt checks remain in place.

3. Successful registration
   - Account is only considered created after successful OTP verification and database commit.
   - The flow redirects to /register/success, which can be viewed only once from its session flag.
   - Shows a success animation, username, Employee ID, welcome email status, and a button to the site's /login route.
   - Attempts a welcome/confirmation email through the existing Brevo configuration, with configured SMTP fallback.
   - If the optional confirmation email fails, the committed account remains created and the success screen still lets the user log in.

4. Files changed
   - app.py
   - templates/register.html
   - templates/account_success.html (new)
   - VERSION_V50.txt (new)
   - FIX_NOTES_2026-10-21_V50_ATTRACTIVE_REGISTRATION.txt (new)

5. Verification boundary
   - Python syntax, Jinja parsing/rendering, HTML parser, and rendered inline JavaScript syntax checks were run locally. The welcome-email payload/escaping/recipient logic was tested with a mocked email-provider response.
   - Full Flask test-client/database integration and actual provider delivery could not be exercised in the available workspace, because Flask dependencies were absent and package installation was blocked by network access.
