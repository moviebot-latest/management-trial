V45 PATCH NOTES — HERO TEXT OVERLAP + NEON/VERCEL DB TIMEOUT

Changes:
1. Mobile hero rotator now displays only the active phrase (no cross-fade stacking), wraps safely, and uses responsive headline sizing.
2. SQLAlchemy Vercel pool increased from 1 connection/no overflow to a modest 3 connections + 2 overflow, with a 20-second pool wait.
3. Database first-run initialization is serialized with a process lock so concurrent /register and /public-stats requests do not all run create_all/schema migration at once.
4. Failed initialization gets a short retry cooldown to prevent request bursts from repeatedly hammering Neon.
5. Rollback cleanup now runs inside an app context so cleanup errors do not hide the original database failure.

Safety:
- No SQL data reset/drop/truncate statements were added.
- Existing tables and records are preserved.
