MANAGEMENT SYSTEM V46 — NEON CONNECTION TIMEOUT + HERO OVERLAP PATCH

Based on V45, with additional database startup-load protection:
1. Vercel SQLAlchemy pool uses pool_size=2, max_overflow=1, pool_timeout=20, pool_pre_ping, pool_recycle and LIFO reuse. This avoids the old 1-connection/0-overflow configuration seen in runtime logs while keeping per-instance connection use modest.
2. /public-stats and /auth-status no longer trigger create_all/schema migrations via the global before_request hook. /public-stats already handles query errors and returns 503 safely. This prevents a frequent landing-page stats call from initiating database initialization at the same time as /register.
3. Keeps the V45 process lock/retry cooldown around DB initialization for routes that require it.
4. Keeps the mobile hero overlap fix and existing Flask templates, routes, migrations, and static assets.

DATA SAFETY: No DROP, TRUNCATE, database reset, or destructive migration added. Existing Neon tables/records are preserved.
