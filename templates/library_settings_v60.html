Manual database backup

Download a full logical JSON backup and store it outside your hosting account. The backup contains member data and password hashes; keep it private.

Download database backup

Restore backup (merge-only)

This restore inserts non-conflicting rows only. It never deletes or overwrites current records. Make a fresh backup first. Restore can still create duplicate business records if source IDs differ.

Automatic backup configuration

For nightly off-site backup on Vercel, configure an S3-compatible bucket and schedule a daily request to /api/cron/library-backup with Authorization: Bearer CRON_SECRET.

Required environment variables: BACKUP_S3_BUCKET, AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_REGION, and a strong CRON_SECRET.

See README.md for setup instructions. The app cannot create a scheduler inside Vercel automatically.
